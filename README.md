# ИФТТ РАН — сайт института и панель управления

Новая реализация сайта Института физики твёрдого тела им. Ю. А. Осипьяна РАН
(прежний адрес — `issp.ac.ru/main`). Публичный сайт на русском и английском
языках и полноценная панель управления содержимым.

**Стек:** Laravel 13 · Inertia.js 3 · React 19 · TypeScript · Tailwind CSS 4 · Tiptap · Pest.

## Возможности

### Публичный сайт

- Главная: баннеры-слайды, блок «Об институте» с показателями, новости (закреплённая + лента),
  ближайшие события, научные направления, лаборатории, избранные публикации, партнёры.
- Новости с рубриками, фильтром по году и поиском; страница новости со счётчиком просмотров и похожими материалами.
- События (семинары, конференции, школы, защиты, лекции): предстоящие / прошедшие, фильтр по типу, страница события.
- Структура института: дирекция, отделы, лаборатории; страница лаборатории (описание, направления,
  сотрудники, публикации, события, контакты).
- Сотрудники: все / дирекция / учёный совет, фильтр по лаборатории, поиск; персональная страница.
- Публикации с фильтрами по году, типу, лаборатории и поиском (включая DOI).
- Документы по разделам (устав, учёный совет, аспирантура, закупки, антикоррупция…), вакансии, статические страницы
  с боковым меню и иерархией, контакты с формой обратной связи (honeypot + rate limit), глобальный поиск.
- Переключение языка RU/EN; при отсутствии перевода показывается русский текст.

### Панель управления (`/admin`)

- Роли: **администратор** (всё) и **редактор** (контент, меню, медиатека, сообщения, корзина).
- Единый декларативный CRUD для 13 типов контента: новости, рубрики, события, страницы, баннеры,
  научные направления, отделы, лаборатории, сотрудники, публикации, документы, вакансии, ссылки.
  Для каждого: поиск, фильтры, сортировка, пагинация, массовые действия, быстрые переключатели
  (опубликовано/активно), дублирование, перетаскивание для сортировки, корзина с восстановлением.
- Формы с вкладками RU/EN, WYSIWYG-редактор (Tiptap: заголовки, списки, ссылки, изображения из медиатеки,
  таблицы, HTML-режим), загрузка файлов и изображений перетаскиванием, автоматические slug.
- Конструктор меню (шапка и подвал, вложенность до 3 уровней, подсказки ссылок).
- Медиатека: загрузка, папки, alt-текст, копирование ссылки, массовое удаление.
- Сообщения с сайта: входящие / непрочитанные / архив, отметки «прочитано» и «отвечено».
- Настройки сайта: название, контакты, карта, показатели на главной, соцсети, подвал, SEO, счётчики.
- Пользователи, профиль и смена пароля, журнал действий, общая корзина, дашборд со статистикой.

## Быстрый старт

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan storage:link
npm install
npm run build        # или npm run dev для разработки
php artisan serve
```

Учётные записи после `--seed`:

| Роль          | E-mail            | Пароль     |
| ------------- | ----------------- | ---------- |
| Администратор | admin@issp.local  | `password` |
| Редактор      | editor@issp.local | `password` |

Смените пароли сразу после первого входа (`/admin/profile`).

## Структура кода

```
app/Admin/                 декларативные ресурсы админки (Field, Resource, Resources/*)
app/Http/Controllers/Admin генерический ResourceController + меню, медиа, сообщения, настройки…
app/Http/Controllers/Site  публичные контроллеры
app/Models/                модели; Concerns: HasTranslations, HasSlug, Publishable, LogsActivity
app/Support/Presenter.php  приведение моделей к данным публичных страниц (с учётом языка)
resources/js/pages/site    публичные страницы (React)
resources/js/pages/admin   страницы панели; resources/{index,form}.tsx — универсальные CRUD-экраны
resources/js/components    UI-кит, карточки сайта, компоненты админки (редактор, загрузка, медиатека)
database/seeders           демо-данные: настройки, меню, структура, контент
```

### Как добавить новый тип контента

1. Создать миграцию и модель (при необходимости подключить `HasTranslations`, `HasSlug`, `Publishable`, `SoftDeletes`).
2. Описать ресурс в `app/Admin/Resources/*Resource.php` набором `Field::…`.
3. Зарегистрировать класс в `app/Admin/Resources::CLASSES`.
   Список, форма, фильтры, валидация, загрузки и корзина появятся автоматически.

## Замечания по данным

Сидеры заполняют сайт демонстрационным содержимым: названия лабораторий и научные направления
соответствуют тематике института, но руководители лабораторий, члены дирекции (кроме директора),
новости, события, публикации и контактные телефоны являются заглушками и должны быть заменены
через панель управления.

Переменные окружения для почты (`MAIL_*`) нужны, чтобы уведомления о сообщениях с сайта уходили на
адреса из настройки «Получатели формы обратной связи».
